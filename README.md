# 🗣️ Porta-Voz — Comunicação Acessível

Um aplicativo web leve, rápido e gratuito de **Comunicação Alternativa e Aumentativa (CAA)** focado em devolver a voz e a dignidade para pessoas com dificuldades ou impossibilidade de fala.

🔗 **Acesse o aplicativo rodando aqui:** [samuelpitta.github.io/porta-voz/](https://samuelpitta.github.io/porta-voz/)

## 🎯 Sobre o Projeto

Muitos sistemas de comunicação médica são complexos, exigem internet rápida ou cobram mensalidades. O **Porta-Voz** nasceu de uma visão diferente: focar na simplicidade e no fator humano. Construído sob a filosofia de MVP (Produto Mínimo Viável), ele prioriza o que realmente importa para pacientes acamados, autistas não-verbais, idosos com demência e pessoas em reabilitação motora e vocal.

## ✨ Principais Funcionalidades

- **Cartões Visuais por Categoria:** Comunicação instantânea de necessidades, ações, sentimentos e família usando emojis de fácil reconhecimento.
- **Botão de Emergência Humanizado:** Um botão vermelho dedicado que salva o nome do cuidador direto na memória do aparelho, chamando por socorro nominalmente (ex: "Socorro, Maria!").
- **Aba de Conversa Social:** Frases prontas focadas na interação humana e combate à solidão (ex: "Como foi o dia?", "Me conte uma história").
- **Barra de Texto Livre (Text-to-Speech):** Permite digitar frases únicas pelo teclado para que o navegador as leia em voz alta.
- **Design Adaptativo:** Funciona perfeitamente em computadores, tablets ou nas telas pequenas de qualquer celular.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído propositalmente sem frameworks pesados para garantir velocidade extrema e funcionamento em dispositivos mais antigos:

- **HTML5** (Semântica e Acessibilidade)
- **CSS3** (Estilização responsiva e UI amigável)
- **JavaScript "Vanilla"** (Lógica, Web Speech API para voz e LocalStorage para memória)
- Hospedagem: **GitHub Pages**

## 🚀 Como usar no seu dispositivo

Não é necessário baixar nada em lojas de aplicativo. 
1. Acesse o [link do projeto](https://samuelpitta.github.io/porta-voz/) pelo navegador do seu celular ou tablet.
2. Salve a página como "Atalho na Tela Inicial" para que ele funcione com aparência de aplicativo nativo.
